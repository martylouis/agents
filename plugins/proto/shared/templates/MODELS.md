# Models

Which model runs each proto tier, one line per harness. A line here wins over proto's built-in defaults (`shared/HARNESS.md` → Known harnesses). Proto asks only for a harness with neither. Edit or delete a line to change it. Git-ignored: it stays on this machine.

- `fast`: exact, self-contained building tasks and screenshot descriptions.
- `strong`: library setup, research, and the second fix round.
