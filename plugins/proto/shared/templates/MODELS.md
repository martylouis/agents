# Models

Which model runs each proto tier, one line per harness. Proto reads the line for the harness it runs in and asks only when that line is missing or names a model the harness no longer offers. Edit or delete a line to change it. Git-ignored: it stays on this machine.

- `fast`: exact, self-contained building tasks and screenshot descriptions.
- `strong`: library setup, research, and the second fix round.
